# Changelog

## 2.0.0 — Framework orchestration & on-premise

- Projet renommé **AfriDoc Intelligence RAG** (`afridoc-intelligence-rag`).
- RAG classique avec LangChain Text Splitters et pipeline LangChain Core LCEL.
- RAG agentique via LangGraph StateGraph à routage borné.
- Inference désactivable, Groq ou endpoint privé OpenAI-compatible.
- Docker Compose d'entreprise avec PostgreSQL, profil Ollama facultatif et port API en loopback.
- README renforcé : valeur pour particuliers/entreprises, sécurité, limites et installation privée.
